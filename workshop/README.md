# Workshop: Building a tool-using agent in Unity

A 90-minute workshop in which participants add a `paint_object` tool to the lab assistant and watch Claude decide when to use it.

- **Lab guide and instructor notes:** https://claude.ai/artifact/3yMhS3p7HKiRJsqyRnUNCm
- **`PaintObjectTool.cs`:** the finished tool from Part 3, for anyone who gets stuck. It's kept outside `unity-project` so Unity doesn't compile it next to a participant's own copy. To use it, copy it into `unity-project/Assets/ClaudeLab/Scripts/Tools/` and add **Paint Object Tool** to **Claude Lab Assistant**.

Status: drafted 2026-11-18. The tool compiles against the project; the workshop hasn't been run or dry-run yet.
